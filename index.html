ABOUT THE GAME

どんなゲーム？

インストール不要。index.html をブラウザで開くだけで、いつでも将棋が楽しめます。 ルールを覚えたての初心者から、本格的な詰みを狙う上級者まで。 かわいいライバルたちが、あなたの「もう一局！」を待っています。

🌸

かわいい3人と対局

元気なエルル、知性派ミウ、天才リリカ。声と表情ゆたかなライバルが盤上を彩ります。

♟️

本格の将棋ルール

成り・持ち駒・二歩禁止・王手・詰み判定まで実装。将棋としてしっかり遊べます。

💖

勝利のご褒美イベント

勝つたびに親密度が深まり、デートやストーリーが解放。集めて埋めるギャラリーも。

GAME FEATURES

充実の機能

本格的な将棋エンジンと、心ときめく演出。その両方を一つの画面に。

🧠

難易度別COM思考

気まぐれな初級、駒得を読む中級、相手の応手まで読む上級。3段階の手応え。

🎨

オリジナル立ち絵

3人それぞれの対局専用全身イラストと、思わずどきっとする敗北表情も。

💞

ご褒美デートイベント

勝利するたびに親密度がアップ。お弁当から告白、結婚式まで全27話。

🖼️

思い出ギャラリー

解放したイベントを保存。いつでも見返せる、二人だけのアルバム。

♟️

全駒の移動と成り

歩から飛車まで全駒に対応。成り・不成も自分で選択できます。

🤝

駒取りと持ち駒

取った駒は持ち駒に。空き升へ打って、攻めも受けも自由自在。

⚖️

反則の禁止判定

二歩・行き所のない駒打ち・王手放置をしっかりチェック。

👑

王手・詰みの判定

王手と詰みを自動で判定。最後の一手まで気が抜けません。

🔊

Web Audio演出

駒の着手音、シーン別BGM、キャラクターボイスで臨場感アップ。

📱

スマートフォン対応

キュートでPOPなレスポンシブUI。スマホでも快適にタップ操作。

GAME SYSTEMS

遊びごたえのシステム

対局だけじゃない。きらきらの“マイルーム体験”が待っています。

🏠 ホーム画面

お気に入りのキャラと背景でお出迎え。解放した画像は左右ボタンで自由に切り替え。

📖 ストーリー

対局に勝つほど解放される、3人それぞれの物語。最新話をいつでも読み返せます。

🛍️ ショップ

ときめきコインで限定BGM・イベント・背景画像を購入。全14種のアイテム。

🎯 ミッション

初対局やギャラリー閲覧など、達成でコインGET。毎日のログインボーナスも。

🪪 キャラクタールーム

誕生日・好きなもの・将棋スタイルまで、3人のプロフィールをじっくり閲覧。

⚙️ 設定

音声・BGMのON/OFFやホームイベント画像の切り替えを自由にカスタマイズ。

HOW TO PLAY

あそびかた

むずかしい操作はなし。あなたは先手、COMは後手です。

  1. 1

    対戦相手を選ぶ

    初級・中級・上級から、今日のライバルを選びましょう。

  2. 2

    駒を動かす

    盤上の駒を選ぶと、光る移動先が表示されます。行きたいマスをタップ。

  3. 3

    持ち駒を打つ

    持ち駒を選び、表示された空き升へ。攻守の切り替えはここから。

  4. 4

    成る／成らない

    成れる場所では「成る」「成らない」を選択。狙いに合わせて。

  5. 5

    詰ませて勝利！

    相手の王を詰ませれば勝利。特別なご褒美イベントが解放されます。
