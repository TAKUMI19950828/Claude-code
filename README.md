# しょうぎむすめ！ 紹介サイト

美少女将棋ゲーム **「しょうぎむすめ！（盤上ノ一手）」** を紹介するための、
1ページ完結のランディングサイトです。ゲーム本体のキュート＆POPな世界観に合わせて制作しています。

## 内容

- **ヒーロー** … タイトルとキャッチコピー、みどころを数字で紹介
- **ゲーム紹介** … どんなゲームかをひと目で
- **キャラクター** … エルル・ミウ・リリカ3人のプロフィールと将棋スタイル
- **特徴** … COM思考・将棋ルール・演出など全10機能
- **システム** … ホーム／ストーリー／ショップ／ミッションなどのやり込み要素
- **あそびかた** … 5ステップの操作ガイド

## ファイル構成

```
index.html     … 紹介ページ本体
landing.css    … スタイル（ゲームと同じカラーパレット・丸ゴシック）
landing.js     … 花びら演出・スクロール表示・ナビ追従などの軽い演出
assets/characters/ … キャラクター画像を置く場所（任意）
```

## 表示方法

`index.html` をブラウザで開くだけで表示できます。ビルドや外部ライブラリは不要です。

## キャラクター画像について

ページはゲーム本体と同じ画像パス（`assets/characters/title-ensemble.webp`、
`eruru.webp`、`miu.webp`、`ririka.webp`）を参照します。

- 画像を `assets/characters/` に置くと、その立ち絵が表示されます。
- 画像が無い場合は、各キャラクターのテーマカラーと駒（歩・銀・龍）を使った
  **CSSのフォールバック表示**に自動で切り替わるため、画像なしでもきれいに見られます。

ゲーム本体の `assets/` フォルダをこのサイトの隣にコピーすると、実際の立ち絵がそのまま表示されます。

## メモ

- レスポンシブ対応（スマートフォン〜デスクトップ）
- `prefers-reduced-motion` に対応し、アニメーションを抑制する設定も尊重します
- 紹介テキストはゲーム内データ（キャラクタープロフィール・実装機能）に基づいています
