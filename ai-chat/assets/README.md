# キャラクター画像置き場

ここに「さくら」の立ち絵（透過PNG推奨）を置くと、アプリに表示されます。
画像が無い場合は、CSSで描いた桜カラーの顔が自動で表示されます。

| ファイル名 | 表示される場面 |
| :--------------------------- | :------------- |
| `sakura-idle.png`     | 待機中（デフォルト） |
| `sakura-thinking.png` | 考え中（返答を生成中） |
| `sakura-talking.png`  | お話し中（返答を表示中） |

- 縦長の立ち絵が綺麗に収まります。
- 1枚だけ用意する場合は、その画像を3つの名前でコピーしてください。
