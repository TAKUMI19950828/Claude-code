# キャラクター画像置き場

「エルル」の立ち絵（透過PNG）を置く場所です。会話の状態に合わせて表示されます。
画像が読み込めない場合は、CSSで描いた桜カラーの顔が自動で表示されます。

| ファイル名 | 表示される場面 |
| :--------------------------------- | :------------- |
| `story-eruru-sprite.png`           | 待機中（デフォルト・ガッツポーズ） |
| `story-eruru-desperate.png`        | 考え中（手を合わせて思案） |
| `story-eruru-smile.png`            | お話し中（両手を広げた笑顔） |
| `story-eruru-tear-smile.png`       | お話し中（泣き笑い） |
| `story-eruru-determined.png`       | お話し中（決め顔） |

「お話し中」の3枚は返答ごとにランダムで切り替わります。
