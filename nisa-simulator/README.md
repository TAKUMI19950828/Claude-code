# つみたて みらいシミュレーター

NISA初心者に「つみたて投資が将来いくらになる？」をやさしく説明するための、1ページ完結の
シミュレーションツールです。対面でスマホ画面を一緒に見るケースと、リンクを送って一人で見て
もらうケースの両方を想定しています。

> 既存の将棋紹介LP（リポジトリ直下）とは独立した自己完結アプリです。直下のファイルには触れません。

## 主な機能

- **4パターンのシミュレーション**（タブ切替・入力すると即時に再計算）
  1. 将来いくら？ 2. 毎月いくら？ 3. 何年かかる？ 4. 最初にいくら？
- **NISA vs 課税口座の比較**（運用益に20.315%課税した場合との差・簡易計算）
- **NISA制度の上限チェック**（毎月10万円超／生涯1,800万円超で注意バナー）
- **想定リターンの目安チップ**（全世界株式・国内株式・バランス型・預金など）
- **結果のシェア**：PNG画像保存（固定サイズの専用カード）／URLコピー（開いた瞬間に結果表示）／X共有
- **「NISAとは？」解説**（非課税のメリット・投資枠・複利の図解）

## 技術スタック

- React 18 + TypeScript + Vite
- Tailwind CSS v3.4（暖色トークン。白文字可/ink専用をWCAG AAで分離）
- Recharts（成長グラフ・遅延ロード）/ html-to-image（画像化）/ lucide-react
- M PLUS Rounded 1c（@fontsource・japanese+latinサブセットのみ）
- Vitest（計算ロジック・URLパラメータ・SSRスモークテスト）

## デプロイ

Netlifyの独立サイトとして公開する想定（`base:'/'`、`netlify.toml` 同梱）。
共有リンク・画像保存は https（secure context）で動作します。

## 設計メモ

計算ロジックは `src/lib/calc.ts` の純関数に集約し、逆算は判別共用体
`{ kind: 'ok' | 'already' | 'unreachable' }` で表現しています。URLパラメータは
`parse → clamp → default` で常に安全な値に劣化します（`src/lib/params.ts`）。

本ツールは投資勧誘を目的としたものではなく、簡易計算による概算です。詳細はフッターの免責事項を参照してください。
