# 💸 お金づかい診断

20代前後の若年層向けの**支出診断サイト**です。
月々の各支出項目を入力していくと、最後に同世代の平均額と比較して
「高い / 平均的 / 低い」を一覧表示。診断ゲーム感覚で楽しめる、
ポップ＆カジュアルなデザインの1ページアプリです。

## ✨ 特徴

- **診断フロー**： トップ → 属性入力（年代・性別） → 金額入力（全10項目・1問ずつ） → 結果
- **金額入力**： スライダー＋テンキー風の直接入力＋クイック加算ボタン、3桁カンマ区切り表示
- **「わからない/使ってない」** を選ぶと0円扱いでスキップ
- **結果画面**： 項目ごとの比較カード（あなた/平均/差分/判定バッジ）、支出合計の比較、
  一番乖離が大きい項目にフォーカスした自動コメント、タイプ名の生成
- **シェア**： X（Twitter）用のシェアテキスト生成＋テキストコピー
- **色分け**： 高い＝赤系 / 平均的＝黄色系 / 低い＝青緑系
- スマホファースト・レスポンシブ対応、`prefers-reduced-motion` 対応

## 🛠 技術構成

- React 18 + Vite
- Tailwind CSS（ポップな配色・角丸・アニメーション）
- 状態管理は `useState` のみ
- フォント： M PLUS Rounded 1c（Google Fonts）

## 🚀 開発

```bash
cd spending-diagnosis
npm install
npm run dev      # 開発サーバー
npm run build    # 本番ビルド（dist/）
npm run preview  # ビルド結果のプレビュー
```

## 📊 平均値データについて

`src/data/averages.js` の数値は、総務省「家計調査」や各種若年層向け消費調査を
参考にした**概算の参考値**であり、正確な統計値ではありません。
データを更新したい場合は、このファイルの数値を書き換えるだけでOKです
（キーは `categories.js` の各項目 `key` と一致させてください）。

診断結果はあくまで娯楽としてお楽しみください。

## ⚙️ 項目を追加・変更するには

`src/data/categories.js` に項目を足し、同じ `key` を `src/data/averages.js` の
各年代に追加すれば、診断項目を増やせます。
