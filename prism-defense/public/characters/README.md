# キャラクター画像の差し替え

このフォルダに以下のファイル名で画像を置くと、自動でゲームに反映されます。

| ファイル名     | キャラ | 色味（添付イメージ）            |
| -------------- | ------ | ------------------------------- |
| `akari.png`    | アカリ | ピンクの桜・和ロリ衣装          |
| `miu.png`      | ミウ   | 水色〜ミントの和装・しゃぼん玉  |
| `ririka.png`   | リリカ | 紫の星空・三日月モチーフ和装    |

## 仕組み（フォールバック）

各キャラの絵は次の順で解決されます（`src/components/CharacterSprite.tsx`）。

1. `characters/<id>.png` … 本番イラスト（あれば最優先）
2. `characters/<id>.svg` … 同梱の仮スプライト
3. `def.emoji`           … 絵文字

つまり **PNG を置くだけ** で差し替え完了。コード変更は不要です。
背景は透過 PNG（正方形・推奨 400×400 以上）が綺麗に収まります。
`.webp` を使いたい場合は `CharacterSprite.tsx` の拡張子を変更してください。
